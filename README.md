# Sécurisation des accès numériques — DGFiP

## Client
Direction générale des finances publiques (DGFiP).
Contexte : système d'information précédemment compromis.

## Objectif
Sécuriser l'accès à plusieurs services numériques, pour deux catégories
d'utilisateurs : les agents et les contribuables.

## Outils / mécanismes
- Authentification multifacteur (MFA)
- Système de jetons pour la gestion des accès

## À créer / fonctionnalités
- Activation de compte et connexion
- Réinitialisation de mot de passe
- Authentification multifacteur (plusieurs facteurs)
- Gestion granulaire de l'accès aux services (via le système de jetons)
- Journalisation des connexions (traçabilité), avec prise en charge de
  plusieurs appareils

## À produire (livrables techniques)
- Schéma / modèle de base de données
- Points de terminaison des API (endpoints)
- Pages du front-end
- Fonctionnalités — à valider : le client en a-t-il réellement besoin ?

## Contraintes à prendre en compte
- Pics d'utilisation lors des échéances fiscales (montée en charge / scalabilité)
- Déploiement sur plusieurs sites / centres
